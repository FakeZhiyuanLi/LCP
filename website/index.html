Sync the sources

Subscribe a class to UCI Canvas and refresh assignments, announcements, calendar events, and modules. Pull selected files from Drive, messages from Gmail, and downloaded Gradescope work into the same library.

Capture the lecture

Start recording from the class you are in. Audio stays associated with that class on your Mac, with optional Drive sync or a separate transcription service when you are ready.

Ask in context

Each class gets its own chat alongside a persistent university chat. Attach files, review the source scope, and share selected material through the local MCP bridge.
